# ZENITH TERMINAL - PLANO DE ARQUITETURA DE DADOS v1.1
# Este documento é o mapa oficial de como os dados fluem do Excel para o Gráfico.

========================================================================
1. FONTE: EXCEL (Aba: 'Dados_RTD')
========================================================================
O sistema lê os dados em tempo real da planilha Excel via biblioteca xlwings.

* CABEÇALHO (Informações do Ativo):
  - [C2] : Preço Atual (Last Price)
  - [H2] : Variação Percentual (%)
  - [A2] : Nome do Ativo (ex: NQM6)

* TABELA DE COMPRAS (Times & Trades):
  - Range: A8:D507
  - Coluna A: Horário (Data/Hora)
  - Coluna B: Preço do Negócio
  - Coluna C: Quantidade (Lotes)

* BANCO DE DADOS: PostgreSQL (Supabase)
  - Persistencia: Todos os trades via NEW_DATA sao salvos permanentemente.
  - Recuperacao: O servidor envia HISTORY_DATA (ultimos 20.000 trades) no F5.
  - Limpeza: Apenas via comando manual (SHUTDOWN / CLEAR).

* TABELA DE VENDAS (Times & Trades):
  - Range: G8:J507
  - Coluna G: Horário (Data/Hora)
  - Coluna H: Preço do Negócio
  - Coluna I: Quantidade (Lotes)

========================================================================
2. MOTOR: PYTHON (scanner.py) - ENDEREÇOS VITAIS
========================================================================
* L. 13 : Nome do arquivo Excel alvo ("Fluxo.xlsm").
* L. 20 : Alternância entre LOCAL e REMOTE (Render).
* L. 46 : on_message() -> Recebe ordens do Gráfico (GET_HISTORY / TOGGLE_MOTOR).
* L. 91 : tx_worker() -> O "Carteiro" que envia dados para o servidor via WebSocket.
* L. 159: clean_price() -> A lógica que remove pontos/vírgulas do Excel.
* L. 320: O Loop principal que varre as 507 linhas a cada 0.001s.

========================================================================
3. SERVIDOR: NODE.JS (server.js) - ENDEREÇOS VITAIS
========================================================================
* L. 10 : WebSocket Server (wss) -> Onde o rádio se conecta.
* L. 25 : startPythonScanner() -> A "Vassoura" que mata processos órfãos e religa o motor.
* L. 30 : TASKKILL -> Comando que limpa o PC de instâncias fantasmas.
* L. 41 : broadcast() -> Função que replica o dado para todos os navegadores.
* L. 70 : app.post('/api/trades') -> Porta de entrada para salvar dados no banco/cache.

========================================================================
4. INFRAESTRUTURA E NUVEM
========================================================================
* REPOSITÓRIO (Git): Código versionado para garantir que nunca percamos o progresso.
* HOSPEDAGEM (Render): zenith-terminal-bvj4.onrender.com
  - O Render hospeda o 'server.js'.
  - O motor Python (scanner.py) roda LOCALMENTE na sua máquina (Windows) para acessar o Excel.

========================================================================
6. REGRAS DE OURO (NÃO ALTERAR SEM CONSULTAR)
========================================================================
1. NUNCA mude o nome da aba 'Dados_RTD' no Excel.
2. O Preço deve estar SEMPRE na coluna C2 para o cabeçalho.
3. Se o Rádio ficar VERMELHO: O server.js caiu ou o Render está hibernando.
4. Se o Rádio ficar VERDE mas não tiver velas: O scanner.py está desligado.
5. F5 (Refresh): O gráfico envia 'GET_HISTORY' (L. 55 do scanner.py) para recuperar dados.
